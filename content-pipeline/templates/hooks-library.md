Rotate formulas; never use the same one twice in a row on a page.
Adapt wording to the page's language and tone.

## Virality scoring (used in the calendar, score each 0–2, total /10)
1. **Hook strength** — would you stop scrolling in 1 second?
2. **Demand proof** — similar topic recently over-performed (data in trend report)?
3. **Shareability** — would someone send it to a friend ("this is so you")?
4. **Save value** — useful enough to save for later?
5. **Timeliness** — tied to a current trend, season, festival, or news?

Only ideas scoring **≥ 7** make the 30 shorts; long-form needs **≥ 8** plus demand proof.
